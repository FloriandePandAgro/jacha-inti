# Refugio de Fauna Silvestre Jacha Inti

Sitio web del refugio — Samaipata, Santa Cruz, Bolivia.
Visitas, voluntariado, animales rescatados. En español, portugués, inglés y francés.

**Sitio en línea:** https://floriandepandagro.github.io/jacha-inti/

## Contenido

| Archivo | Qué es |
|---|---|
| `index.html` | La página completa. Un solo archivo. |
| `img/` | El logo y las 20 fotos del refugio. |
| `docs/Jacha-Inti-Guia-de-Traspaso.pdf` | Qué existe y cómo seguir sin el voluntario. **Leer primero.** |
| `docs/Jacha-Inti-Zona-2-ES.pdf` | Ficha diaria del voluntario, zona 2. Imprimir y plastificar. |
| `docs/Jacha-Inti-Zona-2-FR.pdf` | La misma ficha en francés. |

## Poner el sitio en línea (gratis, un clic)

`Settings` → `Pages` → Source: `Deploy from a branch` → Branch: `main` / `(root)` → `Save`.
En un par de minutos el sitio está en https://floriandepandagro.github.io/jacha-inti/

## Cambiar un precio, un teléfono, un horario

Abrir `index.html`, buscar el dato (Ctrl+F), cambiarlo, guardar. GitHub actualiza el sitio solo.

## Antes de publicar de verdad

1. Quitar el aviso «Borrador para aprobación del refugio» (buscar `draft` en `index.html`).
2. Hacer validar por el refugio: precios, horarios, teléfonos, redes sociales.
3. Reemplazar el enlace de Google Maps por el de la ficha real.
4. Quitar `<meta name="robots" content="noindex,nofollow">` para aparecer en Google.

## Importante

Este repositorio está en la cuenta personal de un voluntario.
**Transferirlo a una cuenta del refugio:** `Settings` → `Danger Zone` → `Transfer ownership`.
Los voluntarios se van; el refugio se queda.
